# Run Viewer (`run-viewer`)

Tkinter GUI for browsing completed find-flakes runs. Designed for collaborators to review results on the microscope PC without CLI knowledge.

```
uv run run-viewer                       # default: scans/ directory
uv run run-viewer --scans-dir path/to/  # custom scans directory
```

## Data Sources

| Section | Source file | Key fields |
|---------|-----------|------------|
| Run list | `checkpoint.json` | `args.preset`, `n_chips`, `step_timing`, `notes` |
| Run list detections | `chip_N/seg/summary.json` | `stats.total_detections` |
| Overview image | `overview_*_stitch_chips_detected.png` | — |
| Seg stats | `chip_N/seg/summary.json` | `stats.tier_1/2/3`, `total_detections` |
| Scoring table | `chip_N/seg/summary.json` | `detections_by_frame` → ranked by tier/score |
| Crop thumbnails | `chip_N/seg/crops/rank*.jpg` | Generated by `rerank_detections.py` |
| R-G scatter | `chip_N/seg/rg_scatter.png` | Generated by `rerank_detections.py` |
| Revisit images | `chip_N/revisit_*/rank*_*.png` | Generated by `revisit` command |

## Features

**Rerank button**: Runs `scripts/rerank_detections.py` in a background thread with the specified top-N. Regenerates crops, mosaic, scatter plot, and summary scoring. The chip view refreshes automatically on completion.

**Image popup**: Clicking any image (overview, crop, revisit, scatter) opens a resizable popup window. The image scales to contain (preserving aspect ratio) as the window is resized. Dismiss with click or Escape.

**Scroll behavior**: Switching between chips scrolls to the chip selector position, so the chip buttons remain visible regardless of content height differences between chips.

## Platform Notes

- **Windows**: Segoe UI font, native tkinter rendering
- **Linux**: DejaVu Sans font (TrueType, antialiased), `clam` ttk theme
- No hardware dependencies — reads only from disk
